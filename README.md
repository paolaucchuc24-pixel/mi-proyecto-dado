# 🎲 Aplicación de Dado en Python

## 📌 Descripción
Este proyecto consiste en desarrollar una aplicación que simula el lanzamiento de un dado. Al ejecutarla, el programa genera un número aleatorio del 1 al 6, representando las posibles caras de un dado tradicional.

## 🎯 Objetivo
Crear una aplicación sencilla en Python que permita simular el lanzamiento de un dado, utilizando números aleatorios y aplicando conceptos básicos de programación.

## ⚙️ Características
- Simula el lanzamiento de un dado de seis caras.
- Genera resultados aleatorios del 1 al 6.
- Permite al usuario obtener diferentes resultados en cada lanzamiento.
- Cuenta con una funcionalidad sencilla y fácil de utilizar.

## 🛠️ Tecnologías utilizadas
- **Python:** lenguaje de programación.
- **Visual Studio Code:** editor de código.
- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para almacenar y compartir el proyecto.

## 📋 Requisitos
- Tener instalado Python 3.
- Contar con un editor de código, como Visual Studio Code.

## 🚀 Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Entrar en la carpeta del proyecto.

3. Ejecutar el archivo principal:

   ```bash
   python dado.py
   ```

   *Nota: Si tu archivo tiene otro nombre, sustituye `dado.py` por el nombre correspondiente.*

## 🎮 Funcionamiento
1. El usuario inicia la aplicación.
2. El programa genera un número aleatorio entre 1 y 6.
3. El resultado representa la cara del dado obtenida.
4. El usuario puede volver a lanzar el dado si la aplicación cuenta con esa opción.
